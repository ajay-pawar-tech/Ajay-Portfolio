# Ajay-Portfolio

Personal portfolio website built with HTML, CSS and JavaScript.

## Folder structure

- `index.html` — main page
- `css/style.css` — main design styles
- `css/responsive.css` — mobile and tablet styles
- `js/script.js` — website interactions
- `js/config.js` — reusable personal details
- `assets/images/` — profile and website images
- `assets/icons/` — icons
- `assets/resume/` — resume PDF

## Run locally

Open this folder in Visual Studio Code. You can open `index.html` in a browser, or use the Live Server extension.

We will develop the website step by step.
